Adicionar vídeos

Cole um link do YouTube por linha (até 25 por envio). Pode adicionar quantos lotes desejar, respeitando o armazenamento disponível.

Ao adicionar um link, você declara que tem permissão para utilizar e republicar o vídeo. O AutoClips apenas cria os cortes; a publicação ocorre após sua aprovação.

O download direto do YouTube pode sofrer bloqueio anti-bot. Links MP4 hospedados também são aceitos. Se a importação for bloqueada, você pode enviar o arquivo original já comprimido abaixo, para o AutoClips gerar os cortes.

Enviar vídeo original (MP4)

Para vídeos longos que o YouTube bloquear: envie o vídeo original ou a versão comprimida, até 180 MB. O AutoClips transcreve e cria cortes para aprovação; não publica automaticamente.

Short pronto (MP4)
