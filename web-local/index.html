3. Conectar ao AutoClips SaaS (opcional)

**Nenhum vídeo vai para o servidor AutoClips.** O original e o corte permanecem neste computador. Ao publicar, o navegador envia o corte diretamente à API do YouTube. O backend registra apenas IDs, metadados e créditos.

Para usar a conta SaaS, configure a URL da API, os dados públicos do Supabase e o Google Client ID. Nenhum original ou MP4 é armazenado no servidor.
